# Текущие приоритеты

_Обновляйте список по мере работы. Ритуал старта/финала сессии: [[Протокол сессии для агента и vault]]._

1. Поддерживать [[Прод деплоится через GitHub Actions на VPS]] — секреты `DEPLOY_*`, зелёный workflow.
2. Следить за [[Telegram Bot шлёт клиентам статусы заказов по notify_preferences]] и админской [[Админская сводка по заказам крутится в фоне server js]].
3. На сервере держать заданными `TELEGRAM_BOT_USERNAME`, `PUBLIC_APP_URL` (HTTPS) и при необходимости `TELEGRAM_USE_LONG_POLLING=true`. Если вернётся возможность принимать webhook — снять флаг long polling.
4. При росте нагрузки оценить [[MySQL описан как опциональная миграция из JSON]] (`backend/README-MYSQL.md`).
5. Укрепить безопасность API и деплоя по итогам обзора 2026-05-02: обязательный `JWT_SECRET` и выключенный dev-login в проде, rate limit и разумные лимиты body, обязательный secret для Telegram webhook, атомарная запись/бэкапы `data.json`, при необходимости pin SSH host key в CI. Подробности: `sessions/2026-05-02 — Аудит безопасности Express и vault.md`.
