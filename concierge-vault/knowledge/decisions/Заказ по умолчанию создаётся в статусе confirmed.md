# Статус по умолчанию

Бэкенд и форма админки задают новый заказ в статусе **confirmed** (не `pending`), чтобы совпадать с операционным процессом и триггерить [[Админская сводка по заказам крутится в фоне server js]] для «зависших» подтверждённых.

Проверять в `server.js` (создание заказа) и UI пустого заказа в админке.
