# Решение: свой `api` вместо Base44

Исторически проект был на Base44; интеграция удалена из зависимостей. Вся работа с HTTP — через [[Клиентский модуль api централизует fetch и сортировки списков]] (`src/api/client.js`), экспорт `api`.

Плюсы: предсказуемые эндпоинты Express, нет внешнего SaaS lock-in.
