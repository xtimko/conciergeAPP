# Для кого продукт

- **Клиенты:** вход только через [[Telegram Mini App выдаёт JWT после проверки initData]], онбординг профиля, заказы с домом/фото/комментариями, бонусы, реферальная программа ([[Реферальные ссылки используют токены CON и start param ref]]).
- **Операции:** роль `admin` — дашборд, заказы, клиенты, финансы (см. [[Админка считает выручку и себестоимость в рублях]]).

Брендинг в UI: текстовый логотип «Concierge», тёмная тема по умолчанию.
