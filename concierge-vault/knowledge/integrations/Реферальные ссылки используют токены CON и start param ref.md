# Рефералы

- В `server.js`: префикс старт-параметра `ref_`, разбор токена ссылки, совместимость со старыми форматами (`referral_code`, внутренний `id`, [[Публичные ID клиентов CLI и заказов CON генерируются в db js]]).
- Ожидающие рефереры хранятся в `pending_referrals` в [[Бэкенд Express хранит состояние в data json рядом с кодом]] до привязки пользователя.

Фронт: страница `Referral.jsx`, утилиты `referralLink.js`.
