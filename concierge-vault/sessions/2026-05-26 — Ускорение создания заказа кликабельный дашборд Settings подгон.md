### 3. Ускорение создания заказа (`src/pages/AdminOrders.jsx`)

**Аккордеон вместо плоской формы.** 5 секций (только Основное раскрыто):
- **Основное**: Товар, Цена + Валюта, fx_rate (если не RUB), Статус
- **Финансы**: Себестоимость
- **Детали товара**: Бренд, Размер, Категория, Фото
- **Доставка**: Срок, Адрес клиента, Примечания
- **Клиент и бонусы**: Имя клиента override, баланс, реферер, режим/сумма

Используется `<Accordion type="multiple" defaultValue={['main']}>` из shadcn/ui.

**Режим «Быстро / Полная».** Переключатель в шапке диалога. В «Быстро» — только Товар + Цена + Валюта (+fx_rate если не RUB). Состояние сохраняется в `localStorage` (`concierge_admin_quick_mode`).

**Smart-defaults через localStorage:**
- `concierge_admin_last_currency` — последняя выбранная валюта
- `concierge_admin_last_category` — последняя категория
- `concierge_admin_last_estimated_days` — последний срок

Хелперы `readLs`, `writeLs`, `buildInitialOrder` в шапке файла. Запоминаются при успешном save, подставляются при `openNew()`.

**Сохранение черновика:**
- `handleDialogClose()` — при закрытии без save, если `isFormDirty(form)`, сохраняет в `localStorage.concierge_admin_order_draft`
- При следующем `openNew()` — проверка наличия черновика, если есть и не пустой — `AlertDialog` «Восстановить? / Очистить»
- При успешном save — черновик чистится

**`Dialog onOpenChange`** теперь использует `handleDialogClose` вместо прямого `setDialogOpen(false)`.
