# Сессия 2026-05-24

## Что сделано

### 1. Бот-команды и постоянная клавиатура (`telegramBotCommands.js`)

Новый модуль `backend/src/telegramBotCommands.js`:
- `buildClientKeyboard()` — ReplyKeyboardMarkup 2×2, `persistent: true`, остаётся внизу чата.
- `handleBotMessage(message, db, opts)` — маршрутизирует команды и нажатия кнопок.

Кнопки (сдержанный стиль для люкс-сегмента):
```
◆ Мой профиль        ◆ Мои заказы
◆ Реферальная программа   → Открыть приложение
```

Команды: `/profile`, `/orders`, `/referral`, `/help` — плюс текст кнопок как триггеры.

Ответы:
- **Профиль** — имя, город, баллы, ID, дата регистрации; предупреждение если профиль не заполнен.
- **Заказы** — активные заказы (статусы pending/confirmed/sourcing/shipping/awaiting_pickup), ищет по `client_telegram_id` и `client_email`, до 8 позиций.
- **Реферальная** — ссылка `t.me/bot?start=ref_TOKEN`, кол-во приглашённых друзей, баланс баллов.
- **Открыть приложение** — ссылка `t.me/bot?startapp`.
- Незарегистрированный пользователь → «Откройте приложение для создания аккаунта».

### 2. Изменения `server.js`

- `handleTelegramStartUpdate` переименован в `handleTelegramUpdate`.
- При `/start` — после welcome с inline-кнопкой отправляется второе сообщение, устанавливающее постоянную клавиатуру.
- Все остальные входящие сообщения → `handleBotMessage`.
- Обновлены webhook и long polling handler.

### 3. Кнопка «Поделиться» в реферальной программе (`src/pages/Referral.jsx`)

Рядом с кнопкой «Скопировать» добавлена кнопка «Поделиться»:
```js
window.Telegram?.WebApp?.openTelegramLink(
  `https://t.me/share/url?url=${encodeURIComponent(referralLink)}&text=${encodeURIComponent(t('shareText', lang))}`
)
```
Открывает нативный диалог Telegram — пользователь выбирает контакты, им уходит реф-ссылка с текстом из i18n `shareText`.

## Решения и нюансы

- ReplyKeyboardMarkup и InlineKeyboardMarkup в Telegram взаимоисключающие в одном сообщении → клавиатура устанавливается отдельным вторым сообщением после welcome.
- `persistent: true` — клавиатура не скрывается после нажатия.
- Стиль кнопок: ◆ для информационных разделов, → для CTA — по запросу владельца (люкс-сегмент, без ярких эмодзи).
- `t.me/share/url` — стандартный Telegram share URL, работает через `openTelegramLink` внутри Mini App.
