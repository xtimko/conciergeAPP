# Сборка фронта

- Конфиг: `vite.config.js`, алиас `@` → каталог `src/`.
- Команды: `npm run dev`, `npm run build` → артефакты в `dist/`.
- Переменные окружения сборки: префикс `VITE_*`, например [[Переменная VITE API BASE задаёт базу API на проде]].
